# Hi, I'm Veronika 👋

Frontend engineer in Edinburgh with 8+ years building accessible React, React Native and TypeScript apps, most recently in regulated fintech.

I like finding what keeps causing the same problem and fixing it at the source: tests, accessibility checks and tooling that make the next change safer. I'm currently open to frontend and React Native roles: remote, hybrid or on-site in Edinburgh.

**Portfolio:** [rveruna.github.io](https://rveruna.github.io/) has every project below as a short case study, with the live demo.

## Things I've built

| Project | What it shows |
|---|---|
| [Payoff Planner](https://github.com/rveruna/payoff-planner) · [live](https://rveruna.github.io/payoff-planner/) | Compares ways of paying off several debts and shows exactly how every number is worked out. Money is exact (whole pence), and property-based tests found that snowball can take longer when a single penny more is paid. 273 tests. |
| [Co-author Explorer](https://github.com/rveruna/coauthor-explorer) · [live](https://rveruna.github.io/coauthor-explorer/) | Who researchers write with, as a live, draggable network from open data, with groups found automatically. A keyboard and table alternative to the canvas, and 336 tests. |
| [Agile Charge Planner](https://github.com/rveruna/agile-charge-planner) · [live](https://rveruna.github.io/agile-charge-planner/) | The cheapest half-hours to charge an electric car, from live UK prices. The planner is plain, tested functions, and the chart has a table with the same figures. |
| [Greenest Time](https://github.com/rveruna/greenest-time) · [live](https://rveruna.github.io/greenest-time/) | An Expo and React Native app (the web build is the same code) that finds the cleanest window to run a washing machine or charge an EV, from the UK Carbon Intensity forecast. |
| [Accessible RN Components](https://github.com/rveruna/accessible-rn-components) · [Storybook](https://rveruna.github.io/accessible-rn-components/) | React Native components whose accessibility is checked five ways: unit tests, contrast tests, an axe audit of every Storybook story, a keyboard check and a mutation check. |
| [Claude Workflow Kit](https://github.com/rveruna/claude-workflow-kit) | A ticket-readiness linter plus Claude Code commands. Code decides what has a right answer, and the model never overrules it. |

Also: [Bus Trip Info](https://github.com/rveruna/bus-trip-info-page) (live buses on a map), [Motion Showcase](https://github.com/rveruna/motion-showcase) (spring physics without a library) and [Country Table](https://github.com/rveruna/country-data-table) (a filterable table with shareable URLs).

Each README says what the project does, how it is tested and where its limits are.
